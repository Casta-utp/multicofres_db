# 📦 MulticofresDB

Sistema de gestión de empleados, clientes, gerentes, proveedores y suministros, implementado con Flask y MySQL.

## 🛠 Tecnologías utilizadas

- Python 3.11
- Flask 2.3.3
- MySQL 8.0.36
- HTML, CSS, Bootstrap
- SQLAlchemy ORM
- Heroku (despliegue web)
